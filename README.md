# React To-Do App 📝

A simple yet functional **To-Do List application** built using **React.js**.  
This project allows users to **add, edit, delete, and persist tasks** using **Local Storage**, ensuring data is not lost on page refresh.

---

## 🌐 [Live Demo](https://monisasmal.github.io/ReactToDoProject/)

## 🚀 Features

- ➕ **Add new tasks**
- ✏️ **Edit existing tasks**
- 🗑️ **Delete individual tasks**
- 🧹 **Remove all tasks at once**
- 💾 **Local Storage integration**
  - Tasks are saved automatically
  - Data persists even after page refresh
- 🔄 Real-time UI updates using React state
- 📱 Responsive and clean user interface

---

## 🛠️ Technologies Used

- **React.js (Functional Components)**
- **React Hooks**
  - `useState`
  - `useEffect`
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**
- **Font Awesome Icons**
- **Local Storage API**

---

## 📦 How It Works

- Tasks are stored as objects with `id` and `name`
- `useState` manages input data and task list
- `useEffect` syncs task data with **localStorage**
- Clicking the **edit icon** enables update mode
- Clicking **remove all** clears the entire list
